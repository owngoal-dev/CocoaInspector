Inspector 0.5.9 is a VoiceOver release: every icon-only button has a name, a row reads as one sentence instead of four fragments, and state that was only drawn on screen is now spoken.

- The buttons drawn as a single glyph were read by the name of the glyph. The menu button on a process and on the record list is now "More Options", the one on the process list is "Sort and Filter", and each says that a tap opens a menu.
- The live-updates button said "Pause Live Updates" even while updates were already paused. It now says "Resume Live Updates" while paused, so its name says what a tap does next.
- A process row, a detail row, a row of the record sheet and a row of the detail table were each read a piece at a time, the separators between the pieces included, and the figures arrived without saying what they counted. Each of those rows is now one stop that names every value it carries.
- A sortable column heading was read by the abbreviation it is squeezed down to — "Pri", "FD", "Refs". It now reads the full name of the sort order and says whether the list is sorted up or down, and Voice Control still answers to the abbreviation printed on screen.
- A screen that is nothing but a spinner read as an empty table. Loading and exporting now say so out loud.
- On the screen that says the inspector is unavailable, the picture beside the title is skipped as decoration and the title is a heading, so VoiceOver can jump straight to it.
- On iOS 13, where a chosen menu item is marked with a checkmark in its title, that checkmark was read as a stray character. The item now says it is selected.
- Rows you touch and hold to copy, rows that open onto the full record, and the credit line at the foot of the process list now say what they do.
- A new build check refuses a label that UIKit would never read out, so a row cannot quietly lose its name again. Nothing visual moved in this release: no layout, type size, color or touch target changed.
