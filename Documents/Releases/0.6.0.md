Inspector 0.6.0 redraws the process list as columns you can scan at a glance, and lets you choose how often it refreshes.

- The process list is a table now. Each row is one line: the icon and name, then PID, CPU, memory and threads, each right-aligned in its own column under a heading. The figures line up from the first row to the last, so a process out of step with the rest stands out. Tap a heading to sort by that column; the active one is tinted and carries an arrow. Threads is a new sort order to match. (#8)
- CPU turns orange from half a core and red from nine tenths, so a process spinning a core is visible without reading a single number. Idle processes stay gray. (#8)
- Where the screen is narrow, the threads column goes first, then PID; CPU always stays. At the accessibility text sizes each row stacks its figures under the name instead. The user name left the row to make room; it is still in the process details, and VoiceOver still reads it on the row. (#8)
- The Sort and Filter menu has a Refresh Interval: 1, 2, 5 or 10 seconds. Five stays the default, the choice is remembered, and a new one takes effect at once rather than after the wait already under way. CPU use is measured over the time that actually passed, so every pace reads correctly. (#4)
- The live-updates button no longer changes width when it switches between live and paused, so the Sort and Filter button beside it stays still. (#5)
- Reopening the app no longer flashes "Connecting to the inspector service…" for a split second. The message appears only when connecting takes longer than three quarters of a second, and then stays long enough to read. The process detail lists got the same treatment for their spinner. (#7)
- The credit line at the foot of the process list sits evenly between the last row and the end of the list, and grows with the text size instead of spilling out of a fixed height. (#6)
